OpenRouter は、いろいろな会社の LLM（大規模言語モデル。文章を生成する AI の本体）を、**1 つの窓口からまとめて呼べるようにする中継サービス**です。OpenAI・Anthropic・Google・オープンソースのモデルなどを、それぞれの会社と個別に契約しなくても、OpenRouter に 1 回登録すれば使えます。

## 何が嬉しいのか

普通にやると、モデルを 1 つ増やすたびに「アカウントを作る・API キーを発行する・支払い方法を登録する・そのモデル専用のコードを書く」が発生します。OpenRouter はそこを肩代わりします。

- **API の形が 1 つに揃う。** OpenAI の API と同じ形（`/chat/completions`）で統一されているので、既存のコードはリクエストの `model` の値を変えるだけでモデルを乗り換えられます
- **支払いが 1 本にまとまる。** 各社への支払いではなく、OpenRouter に前払いしたぶんから引かれます
- **落ちたときに別のモデルへ逃がせる。** 指定したモデルが混雑・障害で応答しないとき、あらかじめ決めておいた別のモデルへ自動で切り替えられます（フォールバック）

## どういうときに向くか

**モデルを比べたい / 乗り換えの可能性があるとき**に効きます。「同じプロンプトを 3 社のモデルに投げて出来を見る」ような検証は、OpenRouter なら `model` の文字列を変えるだけで済みます。

逆に、**使うモデルが 1 つに決まっていて当分変えないなら、旨みは薄い**です。中継が 1 段挟まるぶん、わずかに応答が遅くなり、手数料も乗ります。障害の切り分けをするときも、自分たちのコード・OpenRouter・モデル提供元と、疑う場所が 1 つ増えます。

## 注意する点

- **モデルごとに使える機能が違う。** API の形が同じでも、画像入力や関数呼び出し（Function calling）に対応していないモデルはあります。「呼べる」と「同じことができる」は別です
- **入力したデータの扱いは、経由するモデル提供元の方針に従う。** 中継である以上、OpenRouter だけを見て判断はできません
- 料金・対応モデルの一覧は変わり続けるので、判断するときは[公式ドキュメント](https://openrouter.ai/docs)を見てください
