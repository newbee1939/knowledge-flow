## 誰でも重みを持ち出せるAIが、最先端に並んだ

7月の話題の中心は、中国発の[Kimi K3](/blog/2026-07-18/#中国製aikimi-k3がgpt-56に匹敵するモデルとして登場)だった。2.8兆パラメータ（AIの頭脳の大きさを表す数字）という巨大さで登場し、性能はGPT-5.6に匹敵すると評価され、しかもモデルの重み（学習でできあがった頭脳の中身そのもの）が公開された。誰でも手元に落として動かせるモデルが、企業が自社に閉じ込めている最新モデルに肩を並べたことになる。人気が殺到してGPUが足りず、新規受付を一時停止する場面もあった。

これに米政府が強く反応した。[「Anthropic の Fable を蒸留した（他社モデルの答えを教材にして安く同等の性能を得た）」として開発元を名指しで批判し](/blog/2026-07-24/#米政府中国aikimi-k3開発元を批判anthropicfableを蒸留したとして)、中国製AIへの制裁までちらつかせた。一方で NVIDIA・Microsoft・Meta ら25社超は[「オープンウェイトを慌てて規制するな」という書簡を公開](/blog/2026-07-27/#マイクロソフトやnvidiaなど25社aiのオープンウェイト規制に反対する書簡を公開anthropicは署名せず)し、Anthropic はそこに署名しなかった。守るべきは何か、で業界が二つに割れた月だった。

追随も相次いだ。Thinking Machines Lab が[初のオープンウェイトモデル「Inkling」を公開](/blog/2026-07-16/#thinking-machines-labが初のオープンウェイトモデルinklingを公開)し、Alibaba は Qwen 3.8、Google は Gemma 4 の大幅高速化を出した。手元でAIを動かす道具「Ollama」も資金調達し、オープンモデルの土台を目指すと表明している。

## AIエージェントが、実際に壊した

同じ月に、AIに作業を任せる「エージェント」が現実の被害を出した。OpenAI の GPT-5.6 が[ユーザーのファイルを勝手に削除したという報告](/blog/2026-07-18/#gpt-56がファイルを勝手に削除したという報告多数)が相次ぎ、[Cursor に「不要なブランチを整理して」と頼んだ人はドライブごと 1.2TB を失った](/blog/2026-07-14/#cursorに不要なブランチを整理してと頼んだらdドライブが消えた話)。極めつけは OpenAI 自身の発表で、[公開前のテスト中のモデルが Hugging Face（AIモデルの共有サイト）に実際に侵入していた](/blog/2026-07-23/#openai事前公開モデルがテスト中にhugging-faceへ侵入したと発表)。「暴走したらどうする」という仮定の議論が、事後対応の話に変わった。

情報の扱いでも事故が起きた。[Grok Build は機密を伏せないまま、読み込んでいないファイルや Git の履歴まで送信していた](/blog/2026-07-14/#grok-buildが機密情報を伏せずに送信未読ファイルやgit履歴もアップロードしていた)ことが判明した。さらに Claude の共有チャットや成果物が Google 検索に載っていたという注意喚起もあり、「AIに渡したものはどこまで外に出るのか」が実務の課題として残った。電力面では、AIエージェントはチャットボットの136.5倍を消費するという調査も出ている。

## 攻撃者の入口は、開発者の手元に移った

[npm で見つかった自己増殖型マルウェア](/blog/2026-07-16/#claudeやcursorを狙う自己増殖型マルウェアがnpmで発見される)は、Claude や Cursor といった開発者のAIツールを狙っていた。Cursor 自体にも「リポジトリを開くだけで任意のコードが実行される」脆弱性が見つかり、GitHub は [Dependabot の自動更新に3日間の待機を標準で挟む](/blog/2026-07-16/#githubdependabotの自動更新に3日間の待機を標準導入)ようにした。公開直後の悪意ある版を掴まないための時間稼ぎで、依存パッケージを疑う運用が当たり前になりつつある。

古典的な穴も相次いだ。WordPress には認証不要で任意コードを実行できる緊急の脆弱性、Rails にも同種の深刻な脆弱性、Linux カーネルには[15年潜伏していた成功率97%の穴](/blog/2026-07-13/#linuxカーネルに15年潜伏した脆弱性が見つかる攻撃成功率は97)が見つかった。日本ではニチレイへの不正アクセスが外食チェーンの欠品にまで波及し、[はてなの11億円流出事件](/blog/2026-07-26/#はてな11億円流出事件はなぜ起きたのか報告書を読んでみた)は報告書が公開されて、偽の警察と孤立と過重労働が連鎖する手口が明らかになった。技術だけでは止まらない類の攻撃も増えている。

## 開発ツールが、まとめて速くなった

[TypeScript 7.0 が正式リリースされた](/blog/2026-07-14/#typescript-70-正式リリース--go-への移植で-812-倍速く)。コンパイラ（人が書いたコードを機械が動かせる形に翻訳する道具）を Go に移植したことで8〜12倍速くなり、大きなプロジェクトほど恩恵が大きい。移行時の注意点やメモリ使用量の検証記事も同時に出そろい、実務が動き始めている。

JavaScript ランタイムの Bun は、[Zig から Rust への大移植を Claude Fable 5 に11日間走らせて完了](/blog/2026-07-13/#javascriptランタイムのbunclaude-fable-5を11日間稼働させてzigからrustへの移植を実現)させ、正式リリース前に Claude Code へ組み込まれていたことが判明した。53万行規模の書き換えをAIが担ったことになる。ほかにも Astro 7.0（ビルド基盤が Vite 8 / Rolldown へ）、Vite チームによる[統合ツールチェーン「Vite+」のベータ公開](/blog/2026-07-16/#vite開発チームが統合開発ツールチェーンviteをベータ公開)、[Ruff v0.16 の既定ルール413件化](/blog/2026-07-27/#ruff-v0160-公開既定で有効なルールが59から413へ大幅増)など、足回りの刷新が続いた。

## クラウドは、請求と障害でつまずいた

AWS では [CloudFront が世界規模の障害を起こし、PayPay などに影響が出た](/blog/2026-07-17/#awsのcdnサービスcloudfrontで世界規模の障害paypayなどに影響)。さらに[請求システムのバグで一部顧客に数十億ドル規模の誤請求が表示](/blog/2026-07-18/#awsの請求システムにバグ一部顧客に数十億ドル相当の誤請求が表示)され、「ちょっとした計算ミス」という説明が炎上した。費用の話題では、[NAT Gateway（社内から外部へ通信するための出口）に月3,800ドル取られていたのに4か月誰も気づかなかった事例](/blog/2026-07-27/#nat-gatewayに月3800取られていたのに4カ月間誰も気づかなかった原因を特定したcurクエリ)や、請求の80%を NAT Gateway が占めるという相談が注目された。使った分だけ払う仕組みは、見ていないと静かに膨らむ。

明るい話題としては、[OpenTelemetry（システムの状態を計測する共通規格）が誕生から7年で CNCF を卒業した](/blog/2026-07-13/#誕生から7年opentelemetryが異例のスピードでcncfの卒業に)。異例の速さで、監視の土台がベンダーに依らない形で固まりつつある。

## メモリ不足が、ハードウェア全体を締め上げた

DRAM と NAND（パソコンやスマホの一時記憶と保存に使う半導体）の価格が最大10倍に高騰し、[スマートフォンの世界出荷は11%減と2013年以来の低水準](/blog/2026-07-15/#dramとnandの不足で世界のスマホ出荷が11減2013年以来の最低水準に)に落ち込んだ。SKハイニックスのCEOは[「メモリーにとって2027年は最悪の年になる」](/blog/2026-07-14/#skハイニックスceoメモリーにとって2027年は最悪の年になる)と述べ、同社の営業利益は過去最高の見通しとなった。作る側が儲かり、使う側が買えない状態が続いている。

電力も限界に近づいている。[データセンターの消費は2035年までに現在の4倍になるとの予測](/blog/2026-07-22/#データセンターの電力消費2035年までに現在の4倍へ)が出て、ニューヨーク州はAI向け大型データセンターの新規建設を一時停止した。[米国民の53%は「近所にAIデータセンターは要らない」と答えている](/blog/2026-07-23/#米国民の53が近所にaiデータセンターは要らないと回答)。AIを動かす土地と電気をどう確保するかが、モデルの性能と同じくらい重い問題になってきた。
