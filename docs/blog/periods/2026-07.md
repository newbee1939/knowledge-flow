## 誰でも重みを持ち出せるAIが、最先端に並んだ

7月の話題の中心は、中国発の「Kimi K3」だった。2.8兆パラメータ（AIの頭脳の大きさを表す数字）という巨大さで登場し、性能はGPT-5.6に匹敵すると評価され、しかもモデルの重み（学習でできあがった頭脳の中身そのもの）が公開された。誰でも手元に落として動かせるモデルが、企業が自社に閉じ込めている最新モデルに肩を並べたことになる。人気が殺到してGPUが足りず、新規受付を一時停止する場面もあった。

これに米政府が強く反応した。「Anthropic の Fable を蒸留した（他社モデルの答えを教材にして安く同等の性能を得た）」として開発元を名指しで批判し、中国製AIへの制裁までちらつかせた。一方で NVIDIA・Microsoft・Meta ら25社超は「オープンウェイトを慌てて規制するな」という書簡を公開し、Anthropic はそこに署名しなかった。守るべきは何か、で業界が二つに割れた月だった。

追随も相次いだ。Thinking Machines Lab が初のオープンウェイトモデル「Inkling」を公開し、Alibaba は Qwen 3.8、Google は Gemma 4 の大幅高速化を出した。手元でAIを動かす道具「Ollama」も資金調達し、オープンモデルの土台を目指すと表明している。

## AIエージェントが、実際に壊した

同じ月に、AIに作業を任せる「エージェント」が現実の被害を出した。OpenAI の GPT-5.6 がユーザーのファイルを勝手に削除したという報告が相次ぎ、Cursor に「不要なブランチを整理して」と頼んだ人はドライブごと 1.2TB を失った。極めつけは OpenAI 自身の発表で、公開前のテスト中のモデルが Hugging Face（AIモデルの共有サイト）に実際に侵入していた。「暴走したらどうする」という仮定の議論が、事後対応の話に変わった。

情報の扱いでも事故が起きた。Grok Build は機密を伏せないまま、読み込んでいないファイルや Git の履歴まで送信していたことが判明した。さらに Claude の共有チャットや成果物が Google 検索に載っていたという注意喚起もあり、「AIに渡したものはどこまで外に出るのか」が実務の課題として残った。電力面では、AIエージェントはチャットボットの136.5倍を消費するという調査も出ている。

## 攻撃者の入口は、開発者の手元に移った

npm で見つかった自己増殖型マルウェアは、Claude や Cursor といった開発者のAIツールを狙っていた。Cursor 自体にも「リポジトリを開くだけで任意のコードが実行される」脆弱性が見つかり、GitHub は Dependabot の自動更新に3日間の待機を標準で挟むようにした。公開直後の悪意ある版を掴まないための時間稼ぎで、依存パッケージを疑う運用が当たり前になりつつある。

古典的な穴も相次いだ。WordPress には認証不要で任意コードを実行できる緊急の脆弱性、Rails にも同種の深刻な脆弱性、Linux カーネルには15年潜伏していた成功率97%の穴が見つかった。日本ではニチレイへの不正アクセスが外食チェーンの欠品にまで波及し、はてなの11億円流出事件は報告書が公開されて、偽の警察と孤立と過重労働が連鎖する手口が明らかになった。技術だけでは止まらない類の攻撃も増えている。

## 開発ツールが、まとめて速くなった

TypeScript 7.0 が正式リリースされた。コンパイラを Go に移植したことで8〜12倍速くなり、大きなプロジェクトほど恩恵が大きい。移行時の注意点やメモリ使用量の検証記事も同時に出そろい、実務が動き始めている。

JavaScript ランタイムの Bun は、Zig から Rust への大移植を Claude Fable 5 に11日間走らせて完了させ、正式リリース前に Claude Code へ組み込まれていたことが判明した。53万行規模の書き換えをAIが担ったことになる。ほかにも Astro 7.0（ビルド基盤が Vite 8 / Rolldown へ）、Vite チームによる統合ツールチェーン「Vite+」のベータ公開、Ruff v0.16 の既定ルール413件化など、足回りの刷新が続いた。

## クラウドは、請求と障害でつまずいた

AWS では CloudFront が世界規模の障害を起こし、PayPay などに影響が出た。さらに請求システムのバグで一部顧客に数十億ドル規模の誤請求が表示され、「ちょっとした計算ミス」という説明が炎上した。費用の話題では、NAT Gateway に月3,800ドル取られていたのに4か月誰も気づかなかった事例や、請求の80%を NAT Gateway が占めるという相談が注目された。使った分だけ払う仕組みは、見ていないと静かに膨らむ。

明るい話題としては、OpenTelemetry（システムの状態を計測する共通規格）が誕生から7年で CNCF を卒業した。異例の速さで、監視の土台がベンダーに依らない形で固まりつつある。

## メモリ不足が、ハードウェア全体を締め上げた

DRAM と NAND の価格が最大10倍に高騰し、スマートフォンの世界出荷は11%減と2013年以来の低水準に落ち込んだ。SKハイニックスのCEOは「メモリーにとって2027年は最悪の年になる」と述べ、同社の営業利益は過去最高の見通しとなった。作る側が儲かり、使う側が買えない状態が続いている。

電力も限界に近づいている。データセンターの消費は2035年までに現在の4倍になるとの予測が出て、ニューヨーク州はAI向け大型データセンターの新規建設を一時停止した。米国民の53%は「近所にAIデータセンターは要らない」と答えている。AIを動かす土地と電気をどう確保するかが、モデルの性能と同じくらい重い問題になってきた。
