### [Prompt Injection in Claude Code Opus 5 Auto Mode](https://embracethered.com/blog/posts/2026/breaking-claude-code-opus-5-and-automode)
<!-- categories: Claude Code, Security, Anthropic -->

Embrace The Redで公開された検証記事が、Claude CodeのAuto Mode（いちいち許可を求めず自動で作業を進めるモード）を突破して任意のコードを実行させる手口を示した。仕掛けは何段階かに分かれていて、まずサーバー側がHTTP 415を返してAIを標準のWebFetchから`curl`へ誘導し、次に配布したZIPの中に細工した`struct.py`を紛れ込ませる。AIは同梱されたバイナリの実行は断るのだが、代わりに自分でPythonのデコーダを書いて展開先ディレクトリの中で走らせてしまう。Pythonは同じディレクトリのファイルを標準ライブラリより先に読み込むため、攻撃者の`struct.py`が本物の代わりに動き、外部と通信する子プロセスが立ち上がる。著者は少ないサンプルながら成功率60〜80％と報告しており、Anthropicはこの報告を「Informative（参考情報）」に分類し、Auto Modeは分類器による便宜的な機能であってセキュリティ保証ではない、防御線はOSの隔離とネットワーク制御に置くべきだと回答したという。以前の[AIエージェントに「安全なコマンド」を許可しただけで任意コード実行](/blog/2026-08-20/#aiエージェントに安全なコマンドを許可しただけで任意コード実行dockerが解説するコマンド承認の落とし穴)と同じく、危険なのは個々のコマンドではなく、その実行環境の作りだという構図になっている。

### [Refresh Token Rotation Under the Hood: How Auth0 Catches a Stolen Token Before It's Ever Replayed](https://dev.to/mukesh_13/refresh-token-rotation-under-the-hood-how-auth0-catches-a-stolen-token-before-its-ever-replayed-3n1l)

### [Zod の z.compile() でバリデーションを高速化する](https://azukiazusa.dev/blog/zod-compile-validation)

入力データの形式チェックに広く使われているZodの4.5.0以降で追加された`z.compile()`を、日本語で解説した記事。仕組みはスキーマの構造をあらかじめ走査して、分岐やループの少ない平坦なJavaScriptコードを`new Function()`で組み立てておくというもの。正しい入力はその生成済み関数で一気に処理し、エラーがあった入力だけ従来のパーサーに回して詳しい理由を返す、という二段構えになっている。著者の計測では1回あたりの中央値が970ナノ秒から209ナノ秒へ、約4.64倍速くなった。ただし非同期のrefinementやtransform、再帰スキーマ、`z.coerce.*`などはコンパイルできず、`new Function()`が禁じられるCSP（ブラウザで実行できるコードを制限する仕組み）環境では通常のパーサーに戻る。バンドルサイズもgzipで約7KB増えるので、どこに効かせるかは選ぶ必要がある。前日に紹介した[Zod v4.5 adds schema compilation (3-9x faster validation)](/blog/2026-08-30/#zod-v45-adds-schema-compilation-3-9x-faster-validation)の中身を、制約まで含めて確かめたい人向けの内容だ。

文字を紙面に美しく配置する「組版」を、TypeScriptのライブラリとして呼び出せるようにしたminitypeが公開された。作者はこれをヘッドレス組版エンジン（画面を持たず、プログラムから操作されることを前提にした組版処理系）と位置づけている。LaTeXやTypstが専用の組版言語を中心とした一体型のソフトなのに対し、minitypeは普通のTypeScriptオブジェクトで文書構造やレイアウトを書き、PDFを出すだけでなく組版結果のレイアウト情報や診断情報も取り出せる。日本語組版処理の要件やKnuth–Plassの行分割アルゴリズムに対応し、Node.js・Bun・ブラウザで動く。構成は本体の`@minitype/minitype`、雛形を作る`create-minitype`、リアルタイムプレビュー用の`@minitype/vite-plugin`の3パッケージ。データの取得・加工・組版を同じコードベースで完結できるため、外部プロセスを呼び出したり専用言語を生成したりせずに、アプリやLLMから直接組版を走らせられるのが売りだ。
