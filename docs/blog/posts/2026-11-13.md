<!-- categories: GitHub Actions, Supply Chain, Security -->

### [22-Year-Old PostgreSQL Bug Turned into Remote Code Execution](https://mehmetince.net/part-3-6-how-i-ended-up-turning-a-22-year-old-postgresql-type-confusion-primitive-into-rce-cve-2026-6460)
<!-- categories: PostgreSQL, Security, Database -->

PostgreSQL に22年前から潜んでいた欠陥を、外部からコードを実行される攻撃にまでつなげた手順を研究者がブログで公開した。準備済みの問い合わせの後でデータの型を変えると、古いデータを新しい型として読んでしまうのが原因だ。管理者でなく、最も権限の低いログイン用アカウントでも引き起こせるという。修正は今月9日に出た一連の更新に含まれており、早めの適用が要る。

### [「Node.js」にセキュリティ更新 ～16件の脆弱性を修正、HTTP/2関連が多数](https://forest.watch.impress.co.jp/docs/news/2155706.html)

### [Announcing Rust 1.100.0](https://blog.rust-lang.org/2026/11/12/Rust-1.100.0)

### [AMD-V（AMD SVM）とは](https://e-words.jp/w/AMD-V.html)
<!-- categories: AMD, Hardware -->

AMD の CPU が備える、仮想化をハードウェアで助ける機能の用語解説を IT用語辞典 e-Words が載せている。1台のPCの資源を分け、複数のOSを同時に動かす処理を CPU 側で肩代わりする。ソフトだけで仮想化するより、速く安全に動かせるのが利点だ。Intel の同様の機能「Intel VT」とは、仕様は違うが役割はほぼ同じだという。
