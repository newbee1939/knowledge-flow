### [Debian Code Search: Fast TurboPFor with Go SIMD](https://michael.stapelberg.ch/posts/2026-09-06-dcs-fast-turbopfor-go-simd)

プライバシーを重視した無料のメール・ブログ・サイト運営基盤を25年間続けてきたAutistici/Inventatiが、サービス終了を発表した。運営側の説明では、8月26日にテロ組織の指定を受けたことが理由で、続ければ利用者や関係者に法的・金銭的な危険が及ぶと判断したという。段階的に停止していく途中で、利用者にはデータの控えを取るよう呼びかけている。営利を目的としない共同運営のインフラが、技術ではなく法制度の側で止まる例になった。

### [2027年7月以降、Windows Updateで配信されるプリンタードライバーの仕様が変更される予定](https://garumax.com/windows-update-printer-driver-spec-change-2027-07)
<!-- categories: Windows, Microsoft -->

Windows Updateで配られるプリンターの制御ソフトが、メーカー独自のものから共通規格へ寄せられる。記事によれば、2027年7月1日以降は、セキュリティ更新を除く独自ドライバーの更新が原則として認められなくなる。移行先のIPPやMopriaは主要なプリンターメーカーが共同で作った規格で、最近の機種の多くはすでに対応済みだ。独自ドライバーはメーカーのサイトから入手できるが、「Windows保護印刷モード」を有効にすると削除される点は覚えておきたい。
