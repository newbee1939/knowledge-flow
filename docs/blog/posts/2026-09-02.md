### [第278回 MySQL 9.7で変わったDATE型の挙動を確認してみる](https://gihyo.jp/article/2026/09/mysql-rcn0278)
<!-- categories: MySQL, Database -->

gihyo.jpの連載が、MySQL 9.7のリリースノートに紛れているDATE型の変更をまとめて検証している。多くは正しさが増した修正で、`ADDDATE('0000-01-01', INTERVAL 1 DAY)` が `0000-00-00` ではなく `0000-01-02` を返すようになり、`FROM_DAYS(1)` も `0000-01-01` を返して `TO_DAYS()` との往復が成り立つようになった。運用側で気をつけたいのは残り2つだ。`TIMEDIFF()` にDATEとDATETIMEを混ぜたときNULLではなく差分（例で `36:00:00`）が返るようになったため、NULL判定に頼った分岐が黙って別の道を通る。DATEをBIGINTへ暗黙変換したときの結果も14桁の `20260823000000` から8桁の `20260823` へ変わり、CSV出力や外部連携の値がずれる。[第277回 MySQL 9.6と9.7の新機能について](/blog/2026-08-19/#第277回mysql-96と97の新機能について)で触れたとおり9.7はLTS版なので、移行先として選ぶ機会は多い。

### [io_uring without readahead](https://frn.sh/io-uring/)
<!-- categories: Linux, Performance, Database -->

データベースTursoがio_uring（Linuxの非同期I/O機構）を使うとかえって遅くなる現象を、Fernando Simões氏が実測しながら追いかけた記事。原因はO_DIRECT（カーネルのキャッシュを迂回する指定）で先読みが切れると、キューに常時1件しかI/O要求が乗らず、隣り合うディスク要求をまとめる機会が消える点にあった。TPC-HのQ6で比べると、先読みなしでは約19万6000件の要求がそのままデバイスへ飛ぶのに対し、32ページの先読みを入れると約1万6300件まで減り、統合率は0%から91〜93%へ跳ね上がる。さらに先読みなしのio_uringは通常のシステムコール版より2.8倍遅く（8.55秒対3.02秒）、キャッシュミス率も13.3%対7.7%と悪化していた。非同期にすれば速くなるとは限らず、キューに何件積めているかが本質だという整理が実務的だ。

### [Let’s Use the Emergent CSS random() Function in all the Browsers](https://css-tricks.com/css-random-function-polyfill)
<!-- categories: CSS, Browser -->

CSS-Tricksが、CSSに乱数を持ち込む `random()` 関数を対応していないブラウザでも使えるようにするポリフィル（未対応環境を埋め合わせる補助スクリプト）を紹介している。2025年後半にSafariが最初に実装したものの、ChromeとFirefoxは動きこそあれ時期の保証がなく、実質Apple製ブラウザ限定という状態が続いている。`css-random-polyfill` は、ネイティブ対応があれば自分を無効化し、なければ `--random` で始まるカスタムプロパティを拾って `@csstools/css-calc` で式を解決し、結果をインラインスタイルとして当てる。うまいのは、カスタムプロパティの値には任意の式を書けてJavaScriptから計算済みの値として読める、というCSSの性質を足場にしている点で、従来のCSSポリフィルが陥りがちなパース地獄を避けている。

GIGAZINEによると、LinuxディストリビューションOmarchyの初期設定に、一般ユーザーの権限からroot（管理者）を取れる問題が見つかった。原因は既定ユーザーがdockerグループに入っていたことだ。dockerグループに属していると、root権限で動くDockerデーモンにsudo認証なしで話しかけられるため、実質的に管理者と同等になる。結果として、ユーザーセッション内で動くAIエージェント・ブラウザ・IDEなどが乗っ取られた場合、ホストのファイルシステム全体へアクセスされ任意のコードをroot権限で実行されうる。2026年8月24日に既定構成からdockerグループが外され、バージョン4.0.1で修正済みなので、利用者は速やかな更新が推奨される。手元の開発環境ほど「便利だから」と権限を緩めがちな箇所が、そのまま踏み台になるという典型例だ。
