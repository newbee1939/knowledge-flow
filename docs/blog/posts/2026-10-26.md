### [個人開発者のAPIキー管理、セキュリティー大丈夫ですか？Bitwardenで.envファイル地獄から脱出した話｜Kiku | AI × Bangkok](https://note.com/kiku_ai_bangkok/n/n1a3ad9795dbf)
<!-- categories: Security -->

個人開発者が、APIキーを .env ファイルから Bitwarden へ移した体験を note で公開した。点検すると、9個の .env ファイルに28以上の秘密情報が平文で置かれていたという。.gitignore はGitHubへの流出を防ぐだけで、手元に平文で残る危うさは消えないと著者は気づいた。Mac・Windows・Linuxをまたいで同じキーを使うため、対応の広い Bitwarden を選んだ。

### [Password Manager CLI | Bitwarden](https://bitwarden.com/help/cli)
<!-- categories: Security -->

パスワード管理ツールをコマンドで操作する「Bitwarden CLI」の、Bitwarden 公式の解説ページ。保管庫の操作など、アプリでできることの大半をターミナルから実行できる。Windows・macOS・Linuxで使え、npm などからも入れられる。各コマンドの使い方は `bw --help` で確かめられる。

### [Claude Code での開発における認証情報管理: .env をやめて Bitwarden CLI を使うようにした - Qiita](https://qiita.com/AllegroMoltoV/items/74fce57d602991857107)
<!-- categories: Security, Claude Code -->

Claude Code に作業させるとき、秘密情報を .env に置かず Bitwarden で渡す方法を、Qiita の記事が紹介した。.env は読ませない設定にしても、プロンプトインジェクション（AIを騙す悪意ある指示の埋め込み）などで漏れるおそれがある。著者は Secrets Manager 用の `bws` を使い、権限を絞った期限付きの鍵だけをAIに渡している。必要なときだけ、環境変数として注入できるのも利点だという。
