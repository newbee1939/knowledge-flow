<!-- categories: DNS, Cloudflare, Security -->

<!-- categories: Chrome, DNS, Security -->

### [SGのルール削除をしても通信が切れない！Connection Trackingを検証してみた](https://dev.classmethod.jp/articles/202610-mitsuguchi-connectiontracking-kensho)
<!-- categories: AWS, Security, Network -->

AWS のセキュリティグループのルールを消しても、すでにつながっている通信は切れないことがある、と DevelopersIO の検証記事が示した。原因は Connection Tracking（通過した通信を記録し、戻りを自動で許す仕組み）だ。記録済みの接続は、ルール削除後も続く。送信元を絞った安全な設定ほど記録されて切れにくいため、攻撃時にすぐ遮断したいならネットワークACLを使うべきだとしている。
